# Craftsmanship Rules

## Remove AI Slop Checklist

- [ ] No identical spacing everywhere
- [ ] No default Tailwind shadows
- [ ] No generic hover opacity
- [ ] No abrupt animations
- [ ] No stock-style cards
- [ ] No centered-everything layouts
- [ ] No oversized icons without purpose

## Every Component Needs

- idle state
- hover state
- active state
- focus state
- loading state
- disabled state

## Motion Language

Hover → 180ms

Press → 120ms

Reveal → 240ms

Page → 300ms

Use consistent easing.

## Premium Details

- image zoom
- arrow nudge
- animated underline
- layered shadows
- staggered entrances
- soft gradients
- subtle grain
- backdrop blur
- elegant skeletons

## Human Touches

- real copy
- editorial spacing
- meaningful whitespace
- imperfect rhythm
- authentic photography emphasis

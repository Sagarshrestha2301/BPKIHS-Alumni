# Admin Portal UX/UI

## Dashboard
Show only useful metrics within the administrator's permissions:
- registered/verified alumni,
- pending verification,
- events,
- campaigns,
- donation summaries,
- support,
- reports.

## Verification Queue
Columns:
- applicant,
- programme,
- batch,
- submitted date,
- status,
- reviewer,
- actions.

## Alumni
Search, filter, view, authorized edit, suspend where allowed.

## Moderation — Phase 2
Reports, reason, reporter, content, decision, audit.

## Events
Create/edit/publish/cancel/close registration/gallery.

## Fundraising / Finance
Campaign management, donation records, reconciliation, approved financial summary.

## Support
Queue, assignment, status, messaging.

## Content
Pages, FAQ, Board, previous Boards, media.

## Audit
Actor, action, entity, timestamp, safe metadata.

## UX Safety
High-impact operations should use clear status, confirmation, authorization-aware controls, and non-destructive defaults.

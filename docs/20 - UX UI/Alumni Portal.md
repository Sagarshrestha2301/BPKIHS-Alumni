# Alumni Portal UX/UI

## Dashboard
Potential:
- profile completion,
- verification status,
- upcoming event,
- fundraising highlights,
- notifications where available.

Keep the dashboard focused on useful actions, not decorative analytics.

## Profile
Sections:
```text
Identity
Academic
Professional
Personal
Privacy
Verification
```

## Verification
Show current state, submitted information, requested information, and decision information where appropriate.

## Directory
Search/filter/result/pagination with privacy enforcement.

## Events
Upcoming events, event detail, RSVP state, past events.

## Donations
History, campaign, amount, currency, status, receipt access where applicable.

## Settings
- account,
- password,
- privacy,
- communication/newsletter preferences.

## Community — Phase 2
Potential feed/post/comment/reaction/report interfaces.

## Required States
- incomplete profile,
- verification pending/rejected,
- empty directory,
- no events,
- no donations,
- upload failure,
- server error.

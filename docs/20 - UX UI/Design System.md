# Design System

> Visual design has not started. These are the decisions and artifacts required, not a final visual design.

## 1. Reference
The proposal identifies Dhanayoga Foundation as visual inspiration for high-level nonprofit/trust presentation.

Do not copy exact layouts, branding, text, graphics, assets, or component designs.

## 2. Brand Inputs
Need Association-approved:
- logo,
- colors,
- typography guidance if any,
- photography,
- board portraits,
- approved institutional imagery.

## 3. Core Components

## 4. State Design
Every important interactive element should consider:
- default,
- hover,
- focus,
- disabled,
- loading,
- error,
- success.

## 5. Accessibility
Target WCAG 2.2 AA where practical.

## 6. Responsive
Design mobile-first and test mobile, tablet, desktop.

## 7. Tokens
Define final:
- colors,
- typography,
- spacing,
- radius,
- shadows/elevation,
- motion.

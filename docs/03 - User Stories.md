# User Stories

## Public Visitor
- **US-PUB-001:** As a visitor, I want to understand the Association so I know its purpose and relationship with BPKIHS.
- **US-PUB-002:** As a visitor, I want to find permitted public alumni profiles so I can discover people connected to BPKIHS.
- **US-PUB-003:** As a visitor, I want to view events so I know what is happening.
- **US-PUB-004:** As a permitted donor, I want to donate online so I can support a campaign.

## Authentication
- **US-AUTH-001:** As an eligible graduate, I want to register so I can create my alumni identity.
- **US-AUTH-002:** As a new user, I want to verify my email with OTP so the platform knows I control it.
- **US-AUTH-003:** As a user, I want to create a password so I can authenticate later.
- **US-AUTH-004:** As a user, I want to reset my password so I can recover my account.

## Alumni
- **US-ALU-001:** As an alumnus, I want to maintain my profile so my information stays useful.
- **US-ALU-002:** As an alumnus, I want privacy controls so I decide what others can see.

## Verification
- **US-VER-001:** As an alumnus, I want to submit programme/batch information so the Association can verify me.
- **US-VER-002:** As an administrator, I want to review pending applications so verified status is controlled.
- **US-VER-003:** As an administrator, I want decisions recorded so the process is auditable.

## Directory
- **US-DIR-001:** As a user, I want to search by name so I can find a specific alumnus.
- **US-DIR-002:** As a user, I want to filter by programme and batch so I can find my cohort.
- **US-DIR-003:** As a user, I want to filter by specialisation/location so I can find relevant alumni.

## Events
- **US-EVT-001:** As an eligible user, I want event details so I know when and where it happens.
- **US-EVT-002:** As an eligible user, I want to RSVP so the Association knows who plans to attend.
- **US-EVT-003:** As an administrator, I want to manage event information so it remains accurate.

## Donations
- **US-PAY-001:** As a donor, I want to choose a fundraising campaign so my donation supports a defined initiative.
- **US-PAY-002:** As a donor, I want payment to be secure and correctly recorded.
- **US-PAY-003:** As a donor, I want an acknowledgment/receipt after successful payment.
- **US-PAY-004:** As finance staff, I want to reconcile donations so records match provider/bank information.

## Community — Phase 2 Proposed
- **US-COM-001:** As an eligible alumnus, I want to create a post so I can share an update.
- **US-COM-002:** As a user, I want to report inappropriate content so moderators can review it.
- **US-COM-003:** As a moderator, I want to review reports so community content is handled appropriately.

## Support
- **US-SUP-001:** As a user, I want to submit a support request so I can get help.
- **US-SUP-002:** As staff, I want to manage support requests so issues can be tracked to resolution.

## Acceptance Criteria Pattern
Each story should eventually include:
- requirement IDs,
- preconditions,
- expected result,
- edge cases,
- test IDs.
